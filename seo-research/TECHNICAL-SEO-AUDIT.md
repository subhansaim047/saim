Keep `alt=""` on decorative UI icons so screen readers are not spammed.
- **`public/robots.txt` Crawl Governance:** Properly permits Googlebot, Bingbot, and AI Search bots, disallows `/api/` and `/scroll-frames/` for `Googlebot-Image`, and points to `Sitemap: https://www.saimdev.site/sitemap.xml`. Do **not** add `Disallow: /hq-leathercon/` right away — crawlers must fetch headers first to honor `X-Robots-Tag: noindex, nofollow`.
- **Canonical / Security / Compression / Mobile Baseline:** Verified clean security headers (`CSP`, `X-Content-Type-Options`, `X-Frame-Options`), `beforeFiles` rewrite serving `/` cleanly as HTTP `200`, `SSR` rendering `900–2,674` words on core commercial React routes (`/services`, `/overview`, `/pricing`, `/case-studies`, `/demos`), and deferred Microsoft Clarity loading via `requestIdleCallback` preserving initial paint speed.
